
# Project 05 - GROUPBY & PERCENTOF Functions | Frequency Distribution

## Overview

This project demonstrates how Excel's GROUPBY and PERCENTOF functions can be used to summarize data and create a frequency distribution. It explores how to calculate counts, determine percentages of total counts, and build a dynamic summary using modern Excel formulas.

The project compares traditional PivotTable calculations with formula-based reporting, uses SEQUENCE to generate a helper array, and combines these functions into a final GROUPBY formula that returns both count and percentage results.

## Why This Project Matters

Frequency distributions are useful for understanding how often values occur within a dataset and how individual categories contribute to the overall total. This project strengthened my ability to summarize data, calculate percentages, and present results in a structured format.

GROUPBY and PERCENTOF provide a formula-based approach to creating summaries that can update dynamically. Using SEQUENCE to generate a helper array also demonstrates how modern Excel functions can work together to support more flexible calculations.

These skills are useful in business analytics, finance, FP&A, accounting, operations, and data analysis, where reporting often involves counting records, comparing category proportions, and creating summaries that can be refreshed as data changes.
