# Project 01 - Pivot Tables, Slicers & Charts

## Overview

This project demonstrates Excel's core data analysis tools used to transform raw transactional data into useful information for reporting and decision-making. It explores how Excel Tables, PivotTables, charts, conditional formatting, and slicers can be combined to summarize, analyze, visualize, and interact with structured data.

The project uses sales transaction data to create monthly sales reports, identify top-performing sales amounts, analyze sales trends, and interactively filter results by sales representative.

## What I Learned

```text
Converted raw transactional data into a structured Excel Table to create a dynamic data source for analysis.

Learned how Excel Tables automatically incorporate new records and allow connected reports and charts to use updated data.

Created PivotTables to summarize sales data based on sales representative and month.

Used PivotTable fields to organize data into rows, columns, filters, and values to perform conditional calculations.

Grouped transaction dates into monthly categories to analyze sales trends over time.

Used PivotTables to calculate total sales based on multiple conditions such as sales representative and month.

Applied number formatting directly to PivotTable value fields to improve report readability.

Used conditional formatting to identify and highlight the three largest sales amounts within a PivotTable.

Added new records to an Excel Table and refreshed the PivotTable to update the analysis with the new data.

Created a second PivotTable to summarize monthly sales totals for trend analysis.

Built a line chart from PivotTable data to visualize monthly sales trends.

Applied data visualization principles by removing unnecessary chart elements and focusing the chart on the main message.

Used chart data labels to make specific values easier to interpret while maintaining a clear visual presentation.

Created slicers to interactively filter PivotTable and chart results by sales representative.

Learned how PivotTables, charts, and slicers can work together to create dynamic and interactive data analysis reports.
```

## Why This Project Matters

PivotTables, charts, and slicers are essential Excel tools for analyzing structured business data and turning large amounts of transactional information into meaningful reports. This project strengthened my ability to organize raw data, perform conditional calculations, identify important trends, and communicate insights through interactive visualizations.

These skills are commonly used in business analytics, finance, accounting, FP&A, operations, and data analysis to support data-driven decision-making.
