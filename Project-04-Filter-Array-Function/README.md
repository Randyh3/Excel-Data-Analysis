
# Project 04 - FILTER Array Function & Dynamic Filtering

## Overview

This project demonstrates Excel's modern formula-based filtering tools used to extract records and build dynamic reports from structured data. It explores how the FILTER array function and logical tests can be used to return matching records, apply multiple criteria, and create reports that update automatically.

The project focuses on filtering data based on a single condition, creating a SalesRep-specific customer list, applying an OR logical test across two columns, and understanding how dynamic spilled arrays support flexible data analysis.

## Why This Project Matters

The FILTER function provides a formula-based approach to extracting and reporting records that meet specific criteria. This project strengthened my ability to work with logical tests, combine conditions, and build dynamic reports that respond to changing selections and source data.

Formula-based filtering can reduce repetitive manual steps when working with datasets that need to be reviewed from different perspectives. Instead of repeatedly applying filters or copying matching records into separate reports, a FILTER-based output can update automatically as the criteria or underlying data changes.

This project also strengthened my understanding of modern Excel dynamic array functionality and how logical operators can be used to create flexible filtering solutions.

These skills are useful for business analytics, finance, FP&A, accounting, operations, and data analysis because analysts frequently need to isolate relevant records, review customer or sales activity, apply multiple criteria, and maintain reporting outputs as datasets change.
