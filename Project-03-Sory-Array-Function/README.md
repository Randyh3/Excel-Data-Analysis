# Project 03 - SORT Array Function & Dynamic Sorting

## Overview

This project demonstrates Excel's modern formula-based sorting tools used to transform raw data into dynamic reports. It explores how the SORT array function, dynamic array formulas, UNIQUE, and multi-level sorting can be combined to organize, analyze, and report structured data.

The project focuses on creating dynamic sorted reports, controlling sort columns and sort order, performing multi-level sorting, creating sorted unique lists, and building reports that update automatically when the underlying data changes.

## Why This Project Matters

The SORT function provides a formula-based approach to organizing and reporting structured data dynamically. This project strengthened my ability to control sorting logic, perform multi-level analysis, create sorted unique lists, and build reports that update automatically when the underlying data changes.

Formula-based sorting can reduce repetitive manual steps when working with datasets that are frequently updated. Instead of manually re-sorting a table whenever new records are added, a SORT-based report can automatically reflect changes to the source data.

This project also strengthened my understanding of modern Excel dynamic array functionality and how functions such as SORT and UNIQUE can be combined to create flexible reporting solutions.

These skills are useful for business analytics, finance, FP&A, accounting, operations, and data analysis because analysts frequently need to organize datasets, create dynamic reports, identify top or bottom results, and maintain reporting outputs as new data becomes available.
